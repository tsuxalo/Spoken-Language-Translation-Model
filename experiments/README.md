# Error-Aware Hausa Speech Translation Experiments

## Motivation

The existing project implements a cascaded Hausa-to-English speech translation system:

```text
Hausa speech
    ↓
Hausa-fine-tuned Whisper
    ↓
Hausa transcript
    ↓
NLLB-200
    ↓
English translation
```

The baseline successfully demonstrates end-to-end inference, but its evaluation currently focuses primarily on Hausa ASR Word Error Rate (WER). The English translation stage has not yet been evaluated systematically against reference English translations.

A second limitation is error propagation. NLLB is normally trained to translate clean written Hausa, while the cascade supplies Hausa text generated by an imperfect speech recognizer. The distribution encountered by the translation model during inference therefore differs from the type of text on which multilingual MT systems are typically trained.

## Research Question

Can adaptation to realistic ASR errors improve Hausa-to-English speech translation beyond simply replacing the baseline with a stronger general-purpose model?

More specifically:

> Can a compact Hausa-specialized cascade reduce ASR-to-MT error propagation by adapting the translation model to the actual Hausa transcription errors produced by its upstream speech recognizer?

## New Evaluation Dataset

The experiments use `McGill-NLP/NaijaS2ST`, a parallel Nigerian speech translation dataset containing Hausa and English speech and reference text.

NaijaS2ST is used as a new evaluation environment rather than continuing to evaluate only on FLEURS.

This provides a stronger generalization test because the project's existing Whisper model was fine-tuned on FLEURS Hausa.

## Experiment 1: Translation Model Baselines

We first evaluate machine translation independently from speech recognition.

```text
Gold Hausa
    ↓
NLLB-200
    ↓
English
```

versus:

```text
Gold Hausa
    ↓
AfriNLLB
    ↓
English
```

This experiment asks whether African-language specialization improves Hausa-to-English translation before introducing ASR errors.

Metrics:

* SacreBLEU
* chrF++

## Experiment 2: Measure ASR Error Propagation

NaijaS2ST Hausa audio is processed with the project's existing Hausa Whisper checkpoint.

```text
Hausa speech
    ↓
Whisper-small-ha
    ↓
Noisy Hausa transcript
```

Each noisy transcript is paired with the correct English reference.

We then compare:

```text
Gold Hausa → MT → English
```

with:

```text
ASR Hausa → MT → English
```

The difference between these conditions estimates the translation quality lost because of ASR error propagation.

ASR quality is additionally measured using WER.

## Experiment 3: Error-Aware MT Adaptation

Instead of adapting NLLB only on clean written Hausa, we construct training examples from both clean and ASR-generated Hausa.

```text
Clean Hausa ───────────────┐
                           │
ASR-corrupted Hausa ───────┼──→ LoRA-adapted NLLB → English
                           │
Same English reference ────┘
```

LoRA is used so that only a small fraction of NLLB's parameters need to be updated.

Three training conditions are supported:

1. `clean`
2. `noisy`
3. `mixed`

The primary proposed model is `mixed`.

## Experimental Matrix

| System            | ASR Input        | MT Model | MT Adaptation                   |
| ----------------- | ---------------- | -------- | ------------------------------- |
| Baseline          | Existing Whisper | NLLB-200 | None                            |
| MT specialization | Existing Whisper | AfriNLLB | African-language specialization |
| Clean LoRA        | Existing Whisper | NLLB-200 | Clean Hausa only                |
| Noisy LoRA        | Existing Whisper | NLLB-200 | ASR Hausa only                  |
| Error-aware LoRA  | Existing Whisper | NLLB-200 | Clean + ASR Hausa               |

A later ASR experiment can replace Whisper with stronger Nigerian or multilingual ASR models while keeping the MT evaluation constant.

## Key Ablation

The most important comparison is:

```text
Gold Hausa → MT
```

versus:

```text
ASR Hausa → MT
```

If translation quality drops substantially, ASR error propagation is an important bottleneck.

If the gap is small, the remaining problem is more likely to be the MT model itself.

This makes either outcome scientifically useful.

## Intended Final Claim

No numerical claim should be made before evaluation.

If the hypothesis is supported, the final result can take the form:

> Error-aware Hausa MT adaptation improves [METRIC] by [X] over the generic cascade on held-out Hausa-to-English speech, while updating only [Y]% of the translation model's parameters.

The experiment is designed so that the contribution remains interpretable even if the hypothesis is not supported.

## Research experiments

The initial Whisper → NLLB Hausa-to-English cascade is now being extended
with controlled low-resource speech translation experiments.

The first research direction studies **ASR error propagation and error-aware
machine translation adaptation** using the NaijaS2ST benchmark.

The experiments compare:

- generic NLLB-200
- Africa-specialized AfriNLLB
- clean-text MT adaptation
- ASR-noise-aware MT adaptation
- clean + noisy mixed adaptation

See [`experiments/README.md`](experiments/README.md) for the research
question, experimental design, ablations, and evaluation plan.

## Preliminary Smoke-Test Results

A 25-example development subset was used to validate the Hausa-to-English
MT evaluation pipeline before running the full benchmark.

The source input in this experiment was the **gold Hausa transcript**, so
ASR errors were intentionally excluded.

| Model | BLEU | chrF++ |
|---|---:|---:|
| NLLB-200 distilled 600M | 24.45 | 49.95 |
| AfriNLLB 600M | 25.90 | 49.49 |

These numbers are preliminary smoke-test results and should **not** be
interpreted as final model rankings because the sample contains only
25 aligned development examples.

The initial result is mixed:

- AfriNLLB achieves higher BLEU.
- Generic NLLB achieves slightly higher chrF++.

Therefore, African-language specialization does not yet appear to provide
an unambiguous improvement on this small subset.

The next experiment introduces real ASR errors while holding the English
references and MT models constant. This measures how much translation
quality is lost specifically because of the upstream speech recognizer.

## Preliminary Error-Propagation Results

A 25-utterance smoke test was used to verify the complete evaluation
pipeline before scaling to a randomized multi-speaker evaluation set.

The experiment compared machine translation from the gold Hausa
transcript with translation from the Hausa transcript produced by the
project's existing Whisper-small model.

| Hausa Input | MT Model | BLEU | chrF++ |
|---|---|---:|---:|
| Gold transcript | NLLB-200 600M | 24.45 | 49.95 |
| Whisper ASR transcript | NLLB-200 600M | 8.03 | 33.37 |
| Gold transcript | AfriNLLB 600M | 25.90 | 49.49 |
| Whisper ASR transcript | AfriNLLB 600M | 7.90 | 32.97 |

The existing Whisper model produced a mean per-utterance WER of 42.76%
on this pilot subset.

For NLLB, replacing gold Hausa with ASR-generated Hausa reduced BLEU
from 24.45 to 8.03 and chrF++ from 49.95 to 33.37.

AfriNLLB experienced a comparable degradation, suggesting that swapping
the generic MT component for an Africa-specialized MT checkpoint alone
does not solve the error-propagation problem.

Qualitative inspection revealed several important ASR failure modes,
including:

- corruption of named entities
- loss or substitution of numbers
- lexical substitutions
- omitted content
- occasional hallucinated phrases

These preliminary results motivate the next experiment: adapting the MT
model to the error distribution produced by the upstream Hausa ASR model.

### Important limitation

The initial 25-example smoke test was drawn from the beginning of the
streaming dataset and was dominated by a single speaker. These results
are therefore treated only as pipeline-validation results.

Subsequent experiments use deterministic shuffled sampling across the
NaijaS2ST development data and report both corpus-level and
utterance-level WER.

## Error-Aware Speech Translation Experiments

The project is being extended beyond the original Whisper → NLLB
baseline to study error propagation in low-resource Hausa-to-English
speech translation.

The new experiments use the NaijaS2ST benchmark to compare:

- translation from gold Hausa transcripts
- translation from ASR-generated Hausa
- generic NLLB versus Africa-specialized AfriNLLB
- noise-aware parameter-efficient MT adaptation

Initial smoke tests show a large degradation in translation quality when
gold Hausa transcripts are replaced by Whisper-generated transcripts,
motivating experiments that explicitly adapt the translation model to
real ASR errors.

See [`experiments/README.md`](experiments/README.md) for the experimental
design and preliminary results.
